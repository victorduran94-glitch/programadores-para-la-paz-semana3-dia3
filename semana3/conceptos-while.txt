1. ¿Qué significa repetir instrucciones en programación?

Respuesta: Significa ejecutar un bloque de código más de una vez, ya sea un número fijo de veces o hasta que se cumpla una condición específica. Esto evita escribir el mismo código muchas veces y permite automatizar tareas repetitivas.

2. ¿Qué es un ciclo while?

Respuesta: Es una estructura de control que repite un bloque de instrucciones mientras una condición sea verdadera. El programa evalúa la condición primero y, si se cumple, ejecuta el código dentro del ciclo; luego vuelve a evaluar la condición, y así sucesivamente.

3. ¿Qué significa la condición dentro de un while?

Respuesta: La condición es una expresión que se evalúa como verdadera o falsa. Mientras la condición sea verdadera, el ciclo sigue ejecutándose. Cuando la condición se vuelve falsa, el ciclo se detiene y el programa continúa con las instrucciones siguientes.

4. ¿Por qué es importante cambiar una variable dentro del while?

Respuesta: Porque si ninguna variable que afecta la condición cambia, la condición nunca se volverá falsa y el ciclo nunca terminará. Cambiar una variable (como un contador o un indicador) permite que en algún momento la condición deje de cumplirse y el ciclo finalice correctamente.

5. ¿Qué es un ciclo infinito?

Respuesta: Es un ciclo cuya condición nunca se vuelve falsa, por lo que el programa se ejecuta sin detenerse. Esto puede congelar el programa o la terminal, y generalmente ocurre cuando se olvida actualizar la variable que controla la condición.

8. ¿Qué diferencia hay entre node archivo.js y npm run practicar?

Respuesta: node archivo.js ejecuta directamente un archivo específico usando Node.js. En cambio, npm run practicar ejecuta el script definido en package.json, que puede contener uno o varios comandos, no necesariamente un solo archivo, y puede incluir configuraciones adicionales.

9. ¿Cómo puede servir un while para revisar varias fuentes de información?

Respuesta: Un ciclo while puede recorrer una lista de fuentes de información una por una, verificando cada una hasta encontrar una que sea confiable o hasta agotar todas las opciones. Por ejemplo, se puede revisar fuente 1, luego fuente 2, luego fuente 3, y detenerse al encontrar una fuente verificada, simulando el proceso manual de contrastar información.

10. ¿Cómo puede relacionarse un ciclo con el seguimiento de propuestas comunitarias?

Respuesta: Un ciclo puede representar el seguimiento periódico de una propuesta ciudadana. Por ejemplo, mientras la propuesta no haya sido revisada o aprobada, el ciclo se repite: se verifica el estado, se revisan nuevos comentarios, se actualiza la información. Esto asegura que la comunidad no pierda de vista el avance y que se tomen decisiones en el momento adecuado.
